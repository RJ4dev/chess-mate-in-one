# Первый ряд чёрных — план реализации

Основание: поручение владельца после PR21, 29.10.2026, исходный учебный план, разделы 1 и 2 / блок 1 «Доска и начало игры». База: 98a57ca42d68292410e941724b2d5f44760f544a. Журнал BookStack 169/178.

Цель: два коротких занятия по четыре шага добавляют восемь чёрных фигур на восьмой ряд к предоставленным 16 белым (16→20→24). Сначала ладьи a8/h8 и кони b8/g8, затем слоны c8/f8, ферзь d8 и король e8. Белые остаются снизу. Слева/справа относятся к экрану; чёрный ферзь на тёмной клетке напротив белого. Это уточнение утверждённой последовательности, без смены направления.

Архитектура: новые неизменяемые boardStudy/placePiece карты и две главы в прежнем каталоге. Существующие курсор, помощь, профильное хранилище и capability-gated board-v1; без нового протокола, FEN или схемы данных. JavaScript, Node 24, Playwright 1.58.2, обе HTML-сборки.

Ограничения: версия 0.3.0, без VPS/SQLite/аккаунтов/рейтинга, платных API, слияния или отдельного релиза. Чёрные пешки и самостоятельная сборка 32 с пустой доски остаются открытыми. Данные фигуры не дают достижений за пропуск; показ/помощь учитываются отдельно. Физическая приёмка ребёнком, Android, двумя устройствами не заменяется фикстурами.
