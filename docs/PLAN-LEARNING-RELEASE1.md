Первый выпуск (этапы 0–1, начальная карта из 2):
1. Типизированные упражнения, 12 шахов + 12 защит, три урока по четыре шага, чистая проверка всех верных ходов.
2. Локальный учебный прогресс, изоляция профилей, повтор/продолжение, помощь отдельно.
3. Начальный выбор режима, обучение, квест из готовых глав, любимый мат и свободные мини-режимы; отмена действий и мобильный экран.
4. Опциональный SQLite для учебных достижений в существующем API, транзакции, ограниченные/идемпотентные события. Старое JSON-хранилище рейтинга без миграции.
5. Проверки, независимое ревью, публикация и подготовка отдельного обновления VPS.

Ruling: текущая изолированная рабочая папка без .git — исходный снимок сохранён вне проекта; сравнение и публикация через GitHub connector с проверкой SHA, не создаём второй checkout и не меняем чужую ветку.
Ruling: новый запрос разрешает SQLite вместо запланированного JSON для новых данных — профили/PIN/звёзды остаются в проверенном JSON, обучение в отдельном SQLite; цена решения — два файла для переноса, зато исключена ненужная миграция действующих учётных записей.
Ruling: обычная партия и голос остаются следующими согласованными этапами — в выборе показываем только готовые режимы; цена — полная партия пока не доступна.

Предварительные интерфейсы: exercise -> engine -> UI: только legalChess здесь, sandbox зарезервирован и отвергается обычным движком. Engine -> progress: явная помощь/самостоятельность. Progress -> API: известные ID, без рейтинговых очков. UI -> old app: отдельный контроллер, отмена перед переходом/профилем, текущий мат сохранён. SQLite -> existing JSON: UUID игрока, существующая Bearer-авторизация. Блокер: bridge tunnel_client_not_seen; сервер нельзя считать обновлённым без выполнения и проверки.
