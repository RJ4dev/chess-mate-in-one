# Сборка первого ряда белых

Основание: исходный утверждённый `chess-learning-plan-20261027.md`, раздел 1 (3–5 действий за посещение) и раздел 2, блок 1 «Собирает позицию». Поручение от 29.10.2026 после PR #19. База: `66d0f8f95b8bdfbb78cf57468628115205b0dbef`. Журнал — BookStack 169, предыдущая приёмка — 176.

Результат приращения: восемь белых фигур от пустой доски до первого ряда, два текстовых занятия по четыре шага. Первое: ладьи a1/h1 и кони b1/g1. Второе: слоны c1/f1, ферзь d1, король e1. В каждом занятии есть показ, совместная попытка, практика и самостоятельный шаг. Это тренировка с помощью; самостоятельная сборка всех 32 фигур, пешки и чёрные в этот выпуск не входят. Физическая приёмка остаётся отдельной.

Используется `boardStudy` / `placePiece` с фиксированным префиксом уже поставленных фигур. Уникальное правильное место названо через стороны и соседние фигуры. Это позволяет восстанавливать точную достигнутую доску по существующему курсору без свободного редактора и новой схемы прогресса. При прямом входе во второе занятие четыре начальные фигуры даны упражнением; предыдущие достижения не засчитываются. Исходные карты не мутируют. Пустые и неполные доски не передаются в Chess как FEN.

1. RED→GREEN для восьми диаграмм и двух глав: буквальные префиксы, все 64 ответа на шаг, последовательность 0→8 и короткие занятия. Валидатор допускает 0–31 фигуру, сохраняя запрет перезаписи и некорректных карт.
2. RED→GREEN контроллера: накопление, ошибка и повтор, помощь и перезагрузка, завершение на четырёх и восьми фигурах, прямой вход без чужих отметок. Подписи показа и обратной связи называют доступное действие; частичный ряд не называется полной позицией.
3. Пересобрать автономный HTML и расширить браузерную матрицу обеих сборок: накопление, переход, перезагрузка, помощь, профили, локальная синхронизация, клавиатура и ширина 320 px. Сохранить 60 прежних регрессий. Выполнить полные Node, Python, валидаторы и CI с фиктивным API; git должен остаться чистым.
4. Провести один независимый обзор. Существенные замечания исправлять через RED→GREEN, мелкие сохранять отдельно. Подготовить PR без слияния; доказательства и актуальный итог — в PR и BookStack.

Ограничения: не менять main, релиз, VPS, БД, голос, рейтинг или версию 0.3.0 без допуска. При обзоре проверить, что префикс не засчитывает пропущенные шаги, помощь переживает перезагрузку, вторая глава не закрывает первую, а неподдерживаемый `board-v1` не отправляется серверу. Доски с 0/4/8 фигурами не должны попадать в Chess; подписи всех фаз должны соответствовать доступным действиям.
