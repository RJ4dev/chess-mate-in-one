# Самостоятельная сборка начальной позиции

Основание: поручение владельца после PR23, исходный учебный план (раздел 1, блок 1 «Доска и начало игры»). База: 4e23ec17459c9eb1c01c99db631caaf7f604d737. BookStack 169/180.

## Дизайн

Отдельное текстовое упражнение начинает с полностью пустой доски. Приложение предлагает одну фигуру, ребёнок выбирает любое свободное начальное место этого типа и цвета. Порядок всех 32 фигур перемешан с сохранённым seed, не повторяет обучающие главы. Одинаковые ладьи/кони/слоны/пешки взаимозаменяемы. Без автоматических примеров, координат и отметок ответа; подсказка только по запросу. Белые внизу, чёрные вверху.

Правильная постановка сразу добавляет ровно одну фигуру и предлагает следующую. Занятая/неверная клетка не меняет расстановку; спокойное объяснение без правильного места. Любая ошибка, подсказка или показ одного ответа делает всю попытку assisted, в том числе после перезагрузки. Итоговый факт записывается только после всех 32 верных клеток. Чистый новый повтор может дать independent, исторические флаги сохраняются. Ни одного факта за прежние пропущенные главы.

Можно остановиться в любой момент. Счётчик N/32 и напоминание об отдыхе после каждых 4 постановок. Кнопка «Продолжить позже» возвращает домой с сохранением; «Начать заново» явно обнуляет только текущую попытку. Физическое понимание ребёнком остаётся отдельной проверкой.

Выбран минимальный полноценный путь: чистый движок, отдельный UI и тонкая делегация из learning-ui, вместо переписывания старого движка или 32 автопоказов. Полностью свободный редактор с выбором 12 типов и исправлением произвольной ошибочной доски увеличивает экран и объём; он здесь не нужен. Выбор фигуры приложением снижает нагрузку, но место всегда вспоминает ребёнок.

## Реализация и проверка

1. RED→GREEN движка: перемешивание/инвентарь, все 64 клетки для каждого предложенного типа, альтернативные места, наложение/ошибки, 32 точные фигуры, помощь, восстановление/отбрасывание повреждённых сохранений.
2. Один итоговый exercise/lesson, локальное расширение resume (seed/фактические клетки/assisted), без серверной схемы. Новая capability-группа setup-v1; sync не отправляет факт без неё. UI: пустая доска, образец без места, сохранение каждого действия, помощь/рестарт/пауза/клавиатура; старые маршруты делегируют только новую главу. RED→GREEN реального контроллера/хранилища/синхронизации.
3. Браузер обеих сборок: вся сборка с альтернативами, ошибки/помощь/reload, профили, выход/пауза, рестарт, отсутствие раннего/пропущенного зачёта, unsupported caps с legacy ACK, 320 px. Все 116 регрессий сохраняются. Пересборка root esbuild 0.28.2, полный CI Node 24 / Python 30+2+6/валидаторы/Chromium и один независимый обзор. PR/BookStack с точными SHA/run, без слияния.

Риски обзора: ложный независимый итог после помощи или восстановления; зачисление неполной/подменённой позиции; потеря профильной доски при sync; двойная награда/пропуски; побочные изменения старого UI; громоздкий экран. Требования границ: версия 0.3.0, без production VPS, SQLite, аккаунтов, рейтинга, платных API, релиза и слияния. Реальные Android, ребёнок, два устройства, production-sync остаются открытыми.
