# Шахматор ♟️

Маленькие шахматные приключения для детей. [Открыть игру](https://rj4dev.github.io/chess-mate-in-one/).

## Режимы версии 0.3

При запуске открывается выбор режима; вернуться к нему можно через меню ☰ или название игры.

- **Обучение:** 36 коротких занятий и самостоятельная сборка всей доски: ориентация доски и начальные места фигур, ходы и взятия, спасение обычной фигуры от прямого нападения, шах, защита короля, мат и особые ходы. По четыре шага: показ, совместная попытка, практика и самостоятельный пример. Начальные места изучаются выбором клетки и дополнением расстановки одной показанной фигурой (четыре задания, оба цвета). Два следующих занятия постепенно собирают первый ряд белых с пустой доски (по четыре действия, до восьми фигур). При прямом входе во второе занятие первые четыре фигуры даны упражнением и не засчитываются как пройденные. Ещё два занятия добавляют восемь белых пешек на второй горизонтали (8→12→16 фигур). Два следующих занятия добавляют чёрные ладьи, кони, слоны, ферзя и короля на восьмой ряд к данным 16 белым (16→20→24 фигур), без поворота доски. Пропущенные уроки автоматически не засчитываются. Ещё два занятия добавляют восемь чёрных пешек на седьмую горизонталь (24→28→32). Остальные фигуры предоставлены упражнением; заполнение подготовленной позиции не считается самостоятельной сборкой с пустой доски. «Собери всю доску» начинает с пустой доски и предлагает все 32 фигуры в перемешанном порядке. Ребёнок выбирает любое правильное свободное место одинаковых фигур. Ошибка или подсказка делает всю попытку результатом с помощью; зачёт только после всех 32. Можно остановиться и продолжить. Новый чистый повтор сохраняет историю помощи и может добавить самостоятельный результат. Продолжение местное, итог синхронизируется только при явной поддержке setup-v1. Физическая приёмка ребёнком, Android и двумя устройствами остаётся открытой.
- **Квест:** карта глав с отметками пройденных занятий и продолжением сохранённого урока.
- **Мат за один ход:** прежние 200 проверенных позиций из 51 семьи, пять задач и три сердечка за раунд. Любой матующий ход принимается; невозможный ход не отнимает сердце.
- **Партия вдвоём:** обычная локальная партия на одном устройстве.
- **Против компьютера:** игрок ходит белыми, простой соперник выбирает законный ответ локально в браузере. Партия сохраняется на устройстве отдельно для каждого профиля и не влияет на звёзды или рейтинг. При возвращении ход компьютера возобновляется, если он ещё не был сделан.
- **Мини-игры:** «Найди шах» и «Спаси короля», по 12 позиций для обоих цветов. Принимаются все ходы по условию, в том числе разные защиты от шаха.

Учебные задания не расходуют сердечки и не начисляют конкурентные звёзды. Помощь и самостоятельные решения учитываются отдельно, в том числе после возвращения к заданию. Первые уроки рассчитаны на знакомство с ходами фигур; начальный курс и свободные партии доступны наряду с этими заданиями.

## Игрок и сохранение

Нажмите на «Гость» или имя вверху для регистрации/входа. Уникальное имя и PIN из шести цифр возвращают общий рейтинг звёзд на другом устройстве. PIN хранится на сервере как солёный scrypt-хеш; в публичном списке только имя и звёзды. Общий рейтинг семейный: очки сообщает браузер, это не система защиты от соревновательного мошенничества.

Гостевые награды и учебный прогресс сохраняются в браузере. При запрете хранилища доступна память текущей страницы; игра предупреждает, что после закрытия продолжение исчезнет. Прогресс гостя и каждого профиля разделён. Незавершённый раунд мата пока не восстанавливается; учебное занятие продолжается с законченного шага.

Учебная синхронизация подключается **только когда сервер объявляет готовность** через `/capabilities`. Старый сервер рейтинга остаётся совместимым: до обновления новые уроки работают локально. После обновления SQLite поддерживаемые учебные достижения объединяются между устройствами без дублирования; место продолжения занятия остаётся на своём устройстве. Ориентация доски и начальные места фигур (`board-v1`), а также спасение обычной фигуры (`safety-v1`) сохраняются локально, пока сервер не объявит поддержку этой группы. Старые гостевые результаты не загружаются в профиль автоматически.

## Экран и эффекты

Компактный вид включён по умолчанию. В меню находятся выбор режима, настройки, правила и рейтинг. В настройках — подробный вид, звук, эффекты и спокойная тренировка. Основная игра подстраивается под высоту телефона; длинные окна прокручиваются внутри. Системная настройка уменьшения движения учитывается.

Фигуры плавно движутся, звёзды летят к счётчику, потерянное сердце лопается. При мате/пате крестики показывают закрытые клетки короля; при шахе в режиме мата демонстрируется законная защита. Звук по умолчанию выключен. Голосовой помощник пока не добавлен.

## Запуск и проверки

Корневой `index.html` — автономная сборка без внешних скриптов. Играть гостем можно без серверной части. Исходники в `dist/` открываются через HTTP-сервер, например `python3 -m http.server 8000`, затем `/dist/`.

```sh
npm test
npm run validate
npm run validate:exercises
python3 tests/installer.test.py
python3 tests/upgrade-learning.test.py
python3 tests/upgrade-beginner.test.py
```

Сборка:

```sh
mkdir -p release
npx --yes esbuild@0.28.2 dist/js/app.js --bundle --format=iife --minify --legal-comments=inline --outfile=release/game.js
python3 tools/package-release.py
```

`release/index.html` заменяет корневой `index.html`. Публичные сборки и источник не содержат имён, PIN, токенов или серверной базы игроков.

## Сервер

Текущий HTTPS API рейтинга находится за Tailscale Funnel на порту 10000. Инструкция первоначальной установки — `ops/TAILSCALE.md`; **fresh-installer не используется для обновления уже работающего сервиса**.

`backend/server.mjs` использует стандартную библиотеку Node. JSON-хранилище рейтинга работает с Node20+, опциональное учебное SQLite проверено на Node24. Учебная база включается отдельной переменной `LEARNING_FILE`, требует приватной папки вне репозитория. Транзакции, ограниченные события, идемпотентность и параметры запросов защищают целостность; все учебные запросы используют существующий Bearer-вход.

Владельцу текущего VPS подготовлен `ops/upgrade-learning.py`: по умолчанию только проверка, `--apply` создаёт закрытую резервную копию, обновляет только сервис рейтинга и добавляет один собственный systemd drop-in. Имена/PIN/звёзды не мигрируются. Маршруты Tailscale и соседние сервисы не меняются. Реальное обновление подтверждается отдельно; наличие исходников в GitHub не означает, что VPS уже обновлён. Подробности — `ops/LEARNING.md`.
