# Мат за один! ♟️

Браузерная шахматная игра для детей, которые уже знают ходы фигур и учатся замечать мат. Русский интерфейс и короткие раунды.

## Игра

- Пять задач на раунд и три общих сердечка.
- 200 проверенных учебных позиций из 51 семьи, преимущественно с ладьёй или ферзём.
- Любой законный ход, ставящий мат, засчитывается.
- Невозможный ход не отнимает попытку.
- После ошибки можно увидеть защиту соперника, получить подсказку или разобрать решение.
- Виртуальные звёзды, наклейки и небольшой бонус скорости без ограничения времени.
- Три учебных примера: шах, мат и пат.
- Управление нажатием и с клавиатуры; прогресс хранится в браузере.

Перед первым раундом пройдите «Как играть» вместе с ребёнком. Это первая версия для пробных занятий; отдельные уровни сложности отложены.

## Запуск

`index.html` в корне — автономная сборка: все фигуры, задачи, стили и шахматные правила находятся внутри. Сервер, аккаунты, ключи API и платные обращения не требуются. Для постоянного адреса используйте GitHub Pages.

В репозитории откройте **Settings → Pages → Build and deployment → Deploy from a branch**, выберите **main** и **/(root)**, нажмите **Save**. Публичный адрес появится после первого успешного развёртывания.

Игра также запускается локально: откройте `index.html` в современном браузере. Надёжнее проверять сохранение через HTTP/HTTPS: поведение хранилища для локальных файлов зависит от браузера.

## Прогресс и ограничения

Награды сохраняются после завершения раунда на этом устройстве в этом браузере. Очистка данных браузера удаляет их. Незавершённый раунд после закрытия не восстанавливается. Синхронизации между устройствами, аккаунтов и экспорта в этой версии нет. При отказе постоянного хранилища игра предупреждает о сохранении только на время сеанса.

## Исходники и проверки

- `dist/` — исходная версия из HTML, CSS и JavaScript-модулей; открывается через HTTP-сервер.
- `tests/` — проверки шахматных правил, раунда, наград и сохранения.
- `tools/generate-bank.mjs` — подготовка банка собственных учебных шаблонов.
- `tools/validate-bank.mjs` — отдельная проверка всех позиций.

Для запуска проверок нужен Node.js; устанавливать зависимости не требуется:

```sh
npm test
npm run validate
```

Чтобы проверить исходную версию локально, запустите `python3 -m http.server 8000` из корня репозитория и откройте `http://localhost:8000/dist/`.

Пересборка автономного файла требует esbuild 0.28.2 только на компьютере разработчика:

```sh
mkdir -p release
npx --yes esbuild@0.28.2 dist/js/app.js --bundle --format=iife --minify --legal-comments=inline --outfile=release/game.js
python3 tools/package-release.py
```

Полученный `release/index.html` заменяет корневой `index.html`. Готовый файл уже включён в репозиторий; для обычной игры пересборка не нужна.
